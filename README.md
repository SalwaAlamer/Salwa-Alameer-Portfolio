# Salwa Alameer Portfolio

Premium personal portfolio website for Salwa Alameer, an AI and Computer Vision Computer Science graduate.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project is ready for deployment on Vercel.
