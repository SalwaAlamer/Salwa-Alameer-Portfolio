# Salwa Alameer Portfolio

Personal portfolio website showcasing my work in Artificial Intelligence, Computer Vision, and intelligent systems.

Designed and developed to present selected projects, technical skills, and my professional digital identity through a clean responsive experience.

## Featured Work

- SafeRoad AI — AI-powered pothole detection and monitoring system using YOLOv8 and computer vision.
- Personal Portfolio Website — responsive frontend project focused on UI/UX, branding, and deployment.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Git & GitHub
- Vercel

## Features

- Responsive modern UI
- Dark / Light mode
- Smooth animations
- Project showcase
- Downloadable CV
- GitHub & LinkedIn integration

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project is ready for deployment on Vercel.
